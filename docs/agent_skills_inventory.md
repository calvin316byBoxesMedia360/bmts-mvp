# Inventario De Habilidades De Agentes

Fuente: `C:\Users\no\Downloads\habilidades-agentes-main.zip`

## Resumen

El ZIP contiene un registro de habilidades personalizadas de BoxesMedia360. Para BMTS, las mas utiles no son todas las habilidades disponibles, sino las que ayudan a convertir una idea operativa en producto real, seguro y mantenible.

## Habilidades Relevantes Para BMTS MVP

| Habilidad | Uso En BMTS | Momento |
| --- | --- | --- |
| `intelligent_app_interpreter` | Convertir las entrevistas y necesidades de Beto en decisiones de producto, flujos y pantallas. | Antes de codigo |
| `brainstorming` | Aclarar alcance, variantes de flujo y decisiones de UX antes de implementar. | Antes de cada modulo |
| `writing-plans` | Crear planes de ejecucion por fases antes de tareas grandes. | Antes de construir |
| `executing-plans` | Ejecutar por lotes con checkpoints y revision. | Durante desarrollo |
| `nextjs-app-router-patterns` | Guiar la arquitectura web inicial si el MVP arranca con Next.js. | MVP |
| `react-state-management` | Definir manejo de estado local, server state y cache. | MVP |
| `modern_javascript_patterns` | Mantener calidad de TypeScript/JavaScript. | MVP |
| `error-handling-patterns` | Disenar errores claros para duplicados, invoices, permisos y APIs. | MVP |
| `frontend-security-patterns` | Proteger sesiones, roles y datos sensibles. | MVP |
| `accessibility-compliance` | Evitar interfaces dificiles para oficina/campo y asegurar formularios usables. | MVP |
| `design-system-patterns` | Crear componentes consistentes para dashboard, estados, tablas y formularios. | MVP |
| `brand-identity` | Mantener identidad visual BoxesMedia360/BMTS cuando haya pantallas o reportes. | MVP |

## Recomendacion

Para el primer ciclo de BMTS se recomienda usar este orden:

1. `intelligent_app_interpreter`
2. `brainstorming`
3. `writing-plans`
4. `nextjs-app-router-patterns`
5. `react-state-management`
6. `frontend-security-patterns`
7. `error-handling-patterns`
8. `executing-plans`

Esto mantiene el trabajo enfocado en producto, flujo real, seguridad y ejecucion progresiva.
